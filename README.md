# ADCP Commandline Tools and Libraries written in PERL


## Notes

- The libraries from this repo are required for the re-implemented
shear method (Thurnherr, J. Tech. 2012), for the LADCP_w
vertical-velocity processing software (Thurnherr, IEEE 2011), and for
processing LADCP profiles with external attitude data (Thurnherr et
al., J. Tech., 2017).

- There is currently very little documentation for this software.

- While there is no official support for this software, feel free to
contact the author with questions or requests.

- To find out which version is installed on a system, run "make" in the
install directory.

- Most of the source files use a hard tab of 4 spaces, i.e. they can be
viewed correctly, e.g. with "less -x4".
